# ekey 提取与使用引导（QMC STag 尾标变体）

> **法务立场**：MusicForge 及其格式插件**永不内置**任何账户级机密（ekey、密钥
> 数据库），**永不联网**获取密钥，也**不提供**任何下载或授权绕过能力。
> ekey 与你的音乐文件一一对应——它本来就是随你的账号、你下载的那份文件存在的。
> 本指南只适用于**你自己合法下载、自己账号缓存**的文件。

## 1. 什么是 ekey / 为什么需要你自备

`.mflac0`/`.mflac1`（STag 尾标）文件用**逐曲绑定的密钥**加密：每首歌的加密
密钥各不相同，且与下载它的账号上下文相关。这把密钥的加密形态（ekey）存在于
你的 QQ 音乐客户端缓存/日志中。

社区工具的共同立场是 **no bundled secrets**：工具只提供算法，密钥由你从自己
的客户端提取。这样工具本身不含任何平台机密，你的密钥也不会离开你的电脑。

## 2. 前提

- 你自己的 QQ 音乐账号
- 你**已经用该账号下载**的 `.mflac0`/`.mflac1` 文件（本地缓存）
- MusicForge 已启用 `qmc-migration` 插件并完成 ACK 确认

## 3. 提取路径 A：客户端缓存目录定位（普通用户）

1. 打开 QQ 音乐桌面客户端 → 设置 → 下载与缓存 → 查看缓存/下载目录
2. 在该目录中找到与你文件同名的 `.ekey`/`.json`/日志侧车文件
   （不同客户端版本形态不同；通常与音频缓存同目录）
3. 用记事本打开，复制其中一长串 Base64 字符串（`QQMusic EncV2,Key:...` 开头
   或纯 Base64 均支持）

## 4. 提取路径 B：客户端调试日志（技术用户）

部分版本会把 ekey 写入调试日志：搜索文件名对应的条目，取 `ekey` 字段值。

## 5. 导入 MusicForge

- **GUI**：「AI 与插件」面板 → `qmc-migration` 迁移区 → 在 **ekey 输入框**
  粘贴 → 点「选择文件并迁移」
- **CLI**：`musicforge convert --format-plugin qmc-migration <file> --ekey <ekey>`

ekey 只会经本地进程间传递给插件，**绝不写入网络请求**（插件 `network=false`
为 CI 断言铁律）。

## 6. 常见问题

- **`QMC-EKEY-REQUIRED`**：文件是 STag 尾标变体但未提供 ekey——在输入框填入
  后重试；静态表变体（qmc0/qmcflac 等）不需要 ekey。
- **`QMC-EKEY-INVALID`**：ekey 与文件不匹配（最常见：复制不完整、或 ekey 属于
  另一首歌/另一个账号的下载）。请确认完整复制、且来自同一文件的所属账号。
- **缓存被清理后**：ekey 随缓存一起消失，需要重新登录账号下载一次才能再次
  提取——这是客户端行为，MusicForge 无法（也不会）替代。
- **`.mgg`/`.mgg1`（QTag 尾标）暂不支持解密**：内嵌密钥结构不同，插件目前
  仅识别报告；见插件仓 README 审计表 X49 裁决。
